# 서울시 폐의약품 수거시설 분포 및 접근성 격차 분석

서울시 9개 자치구의 폐의약품 수거시설 공공데이터를 활용하여 시설 위치와 지역별 분포를 시각화하고, 인구 대비 시설 설치 수준 및 시설 간 공간적 분포 차이를 분석하는 프로젝트입니다.

Python을 이용한 데이터 전처리 및 통계 분석과 React 기반 웹사이트 구현을 통해 분석 결과를 사용자가 직접 탐색할 수 있도록 구성했습니다.

> **분석 범위:** 서울특별시 9개 자치구  
> **시설 기록:** 총 233건  
> **좌표 확보:** 233건 (100%)  
> **평균 최근접 시설 거리:** 약 458m (직선거리 기준)

---

## 1. 프로젝트 개요

### 프로젝트 목적

폐의약품은 일반 생활폐기물과 구분하여 적절하게 배출해야 합니다. 이에 따라 지역별 수거시설 정보를 확인하고, 시설이 어떤 형태로 분포되어 있는지 분석하고자 했습니다.

본 프로젝트의 주요 목표는 다음과 같습니다.

- 서울시 일부 자치구의 폐의약품 수거시설 위치 데이터 수집 및 통합
- 자치구별 시설 기록 수와 인구 대비 시설 비율 비교
- 시설 간 최근접 직선거리 분석
- 고령인구 규모와 수거시설 기록 수의 관계 분석
- 분석 결과를 지도와 그래프로 시각화하는 웹사이트 구현

### 분석 대상 지역

서울특별시 9개 자치구를 대상으로 분석했습니다.

| 자치구 | 시설 기록 수 |
|---|---:|
| 강동구 | 21 |
| 관악구 | 21 |
| 구로구 | 22 |
| 마포구 | 35 |
| 서초구 | 41 |
| 성북구 | 42 |
| 양천구 | 6 |
| 중구 | 29 |
| 중랑구 | 16 |
| **합계** | **233** |

본 데이터는 서울시 전체 25개 자치구를 대표하지 않습니다.

## 2. 활용 데이터

| 데이터 | 활용 목적 | 기준 시점 |
|---|---|---|
| 자치구별 폐의약품 수거시설 위치 | 시설 위치 시각화 및 공간 분석 | 자치구별 상이 |
| 서울시 주민등록인구 | 전체 인구 및 고령인구 대비 시설 비율 | 2026년 2분기 |
| 서울시 길단위 유동인구 | 지역별 유동인구 특성 비교 | 2026년 2분기 |

## 3. 데이터 전처리 및 품질 검증

서로 다른 자치구에서 제공한 시설 데이터를 통합하기 위해 데이터 전처리 및 검증 과정을 수행했습니다.

### 3.1 데이터 표준화

- 자치구별로 다른 컬럼명과 데이터 형식 통일
- 시설명 및 주소 데이터 정리
- 위도·경도 컬럼의 숫자 형식 검증
- 시설 기록의 중복 및 품질 검토
- 자료 기준일과 출처 정보 보존

### 3.2 좌표 보완

초기 시설 데이터 233건 중 227건은 좌표를 보유하고 있었으나, 양천구 시설 6건은 좌표가 누락되어 있었습니다.

이를 해결하기 위해 다음 과정을 진행했습니다.

1. 양천구 시설 6건의 주소 추출
2. Kakao Local API를 이용한 주소 기반 지오코딩
3. 반환된 도로명주소와 자치구 정보 검증
4. 검증된 좌표를 기존 시설 데이터에 병합
5. 기존 227건의 좌표가 변경되지 않았는지 확인
6. 최종 233건의 좌표 유효성 및 데이터 일관성 검증

**최종 검증 결과**

| 검증 항목 | 결과 |
|---|---:|
| 전체 시설 기록 | 233건 |
| 유효 좌표 | 233건 |
| 좌표 누락 | 0건 |
| 기존 좌표 보존 | 227건 |
| 양천구 추가 좌표 | 6건 |
| 동일 좌표 기록 | 6건 (3개 그룹) |
| 수동 검토 필요 기록 | 0건 |

양천구 6건은 2020년 공개 자료의 주소를 기반으로 좌표를 보완한 기록이며, 시설의 현재 운영 여부를 확인한 것은 아닙니다.

## 4. 주요 분석 방법

### 4.1 인구 대비 시설 비율

단순 시설 기록 수뿐 아니라 자치구별 인구 규모를 고려하여 시설 분포를 비교했습니다.

**전체 인구 1만 명당 시설 수**

\[
\frac{\text{시설 기록 수}}{\text{주민등록 총인구}} \times 10,000
\]

**고령인구 1만 명당 시설 수**

\[
\frac{\text{시설 기록 수}}{\text{65세 이상 주민등록인구}} \times 10,000
\]

### 4.2 최근접 시설 거리 분석

각 시설에서 가장 가까운 다른 수록 시설까지의 직선거리를 계산했습니다.

거리 계산에는 위도와 경도를 사용하는 Haversine 공식을 적용했습니다.

- 전체 분석 대상: 233건
- 분석 지역: 9개 자치구
- 동일 좌표를 가진 서로 다른 기록은 거리 0m로 계산
- 가장 가까운 시설을 찾을 때 자치구 경계를 제한하지 않음
- 동일 좌표를 제외한 최근접 거리도 보조 지표로 계산

이 분석은 시설 간 간격을 측정한 것으로, 주민의 실제 도보거리나 이동시간을 의미하지 않습니다.

### 4.3 고령인구와 수거시설 수의 상관관계

9개 자치구를 대상으로 다음 두 변수의 Pearson 상관계수를 계산했습니다.

- X: 65세 이상 주민등록인구 수
- Y: 폐의약품 수거시설 기록 수

이를 통해 고령인구 규모와 수거시설 기록 수 사이의 선형 관계를 살펴보았습니다.

### 4.4 월별 수거 처리량 분석

2024년 월별 수거 처리량을 대상으로 다음 지표를 계산했습니다.

- 12개월 원자료 합계
- 월평균
- 월별 표준편차
- 변동계수(CV)
- 최고 및 최저 처리량 월

## 9. 실행 방법

Windows PowerShell을 기준으로 설명합니다.

### 9.1 프로젝트 다운로드

```powershell
git clone https://github.com/yuna830/medicine-map.git

cd medicine-map
```

### 9.2 Python 가상환경 생성

```powershell
python -m venv .venv

.\.venv\Scripts\Activate.ps1
```

### 9.3 Python 라이브러리 설치

```powershell
python -m pip install -r requirements.txt
```

### 9.4 데이터 분석 실행

분석에 필요한 원본 및 중간 데이터가 준비되어 있다는 전제에서 다음 스크립트를 사용할 수 있습니다.

**기본 데이터 처리**

```powershell
python src\01_audit.py
python src\02_preprocess.py
python src\03_validate.py
python src\04_analyze.py
```

**추가 데이터 분석**

```powershell
python src\07_population_flow.py
python src\08_collection_volume.py
```

**양천구 좌표 보완 및 검증**

```powershell
python src\10_geocode_yangcheon.py
python src\11_verify_yangcheon.py
python src\12_merge_yangcheon.py
python src\13_validate_geocoded.py
```

양천구 지오코딩을 새로 수행하려면 개인 Kakao REST API 키를 로컬 환경변수로 설정해야 합니다. API 키는 GitHub에 업로드하지 않습니다.

**최신 공간 분석 및 웹 데이터 생성**

```powershell
python src\14_reanalyze_spatial.py
python src\09_prepare_web_data.py
```

`06_spatial.py`는 초기 분석 단계에서 사용한 스크립트이며, 최신 233건의 공간 분석 결과를 유지하기 위해 최종 분석에는 `14_reanalyze_spatial.py`를 사용합니다.

### 9.5 프론트엔드 실행

```powershell
cd frontend

npm install

npm run dev
```

로컬 개발 서버 주소는 일반적으로 다음과 같습니다.

```text
http://localhost:5173/
```

Kakao 지도 사용을 위해 `frontend/.env.local`에 지도 JavaScript 키를 설정해야 합니다.

```dotenv
VITE_KAKAO_MAP_KEY=YOUR_KAKAO_JAVASCRIPT_KEY
```

실제 코드에서 사용하는 환경변수 이름은 `KakaoMap` 구성에 맞춰 확인해야 합니다.

### 9.6 웹사이트용 JSON 갱신

프로젝트 최상위 폴더에서 실행합니다.

```powershell
python src\09_prepare_web_data.py

Copy-Item "data\web\*.json" "frontend\public\data\" -Force
```

공간 분석 JSON 역시 프론트엔드에서 필요하므로, 최신 분석 결과를 생성한 후 다음 파일이 존재하는지 확인해야 합니다.


## 10. 분석의 한계 및 유의사항

- 서울시 전체가 아닌 9개 자치구를 분석했습니다.
- 시설 자료의 기준일은 자치구마다 다르며, 현재 운영 여부는 확인되지 않았습니다.
- 양천구 6건은 2020년 공개 자료의 주소를 기반으로 좌표를 보완했습니다.
- 시설 간 거리는 직선거리 기준으로 실제 이동거리나 이동시간과 차이가 있습니다.
- 2024년 수거 처리량의 공식 측정 단위는 추가 확인이 필요합니다.
- 서로 다른 기준 시점의 자료를 직접 비교하여 시설 운영 효율로 해석하기는 어렵습니다.

## 12. 프로젝트 의의

본 프로젝트는 공공데이터를 수집하고 시각화하는 데 그치지 않고, 데이터 표준화와 품질 검증, 누락 좌표 보완, 공간 분석, 통계 분석 및 웹사이트 구현까지 수행한 프로젝트입니다.

특히 서로 다른 출처의 데이터를 통합하고, 양천구 좌표 누락 문제를 해결하여 전체 233건에 대한 공간 분석을 수행할 수 있도록 개선했습니다.

이를 통해 공공데이터의 품질과 기준 시점이 분석 결과에 미치는 영향을 확인하고, 분석 과정과 결과를 사용자가 직접 탐색할 수 있는 웹서비스 형태로 구현했습니다.
