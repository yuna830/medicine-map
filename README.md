
# 서울시 폐의약품 수거시설 분포 및 공간적 격차 분석

서울시 9개 자치구의 폐의약품 수거시설 공공데이터를 활용하여 시설 위치와 지역별 분포를 시각화하고, 인구 대비 시설 기록 비율 및 시설 간 공간적 차이를 분석한 프로젝트입니다.

Python을 이용해 공공데이터를 수집·정제·검증하고, React와 Kakao Maps를 활용하여 분석 결과를 직접 탐색할 수 있는 웹 대시보드를 구현했습니다.

**GitHub:** https://github.com/yuna830/medicine-map

## 1. 프로젝트 개요

### 1.1 연구 배경

폐의약품은 일반 생활폐기물과 구분하여 적절한 수거시설에 배출해야 합니다.

그러나 지역별로 수거시설이 얼마나 분포되어 있는지, 인구 규모에 비해 어느 정도의 시설이 확보되어 있는지 비교하기는 쉽지 않습니다.

본 프로젝트는 공개된 시설 위치정보와 인구 및 수거 처리량 데이터를 통합하여 지역별 시설 분포와 공간적 특성을 분석하는 것을 목적으로 합니다.

### 1.2 분석 목적

- 자치구별 폐의약품 수거시설 위치 및 분포 시각화
- 전체 인구 대비 시설 기록 비율 비교
- 65세 이상 인구 대비 시설 기록 비율 비교
- 시설 간 최근접 직선거리 분석
- 월별 폐의약품 수거 처리량 변화 분석
- 고령인구 수와 시설 기록 수의 상관관계 분석

### 1.3 분석 범위

## 4. 데이터 분석 방법

### 4.1 전체 인구 대비 시설 기록 비율

자치구별 인구 규모의 차이를 고려하여 시설 기록 수를 비교했습니다.

```text
전체 인구 1만 명당 시설 기록 수
= 시설 기록 수 / 전체 주민등록인구 × 10,000
```

### 4.2 고령인구 대비 시설 기록 비율

65세 이상 주민등록인구를 기준으로 시설 기록 비율을 계산했습니다.

```text
고령인구 1만 명당 시설 기록 수
= 시설 기록 수 / 65세 이상 주민등록인구 × 10,000
```

이를 통해 고령인구 규모를 고려한 자치구별 시설 기록 비율을 비교했습니다.

### 4.3 시설 간 최근접 직선거리

각 시설에서 가장 가까운 다른 수록 시설까지의 거리를 계산했습니다.

좌표 간 거리 계산에는 Haversine 공식을 사용했습니다.

```text
평균 최근접 시설 간 거리
= 각 시설의 최근접 다른 시설까지 직선거리의 합
  / 분석 대상 시설 기록 수
```

동일 좌표를 가진 서로 다른 시설 기록은 최근접 거리가 0m가 될 수 있습니다.

또한 이 거리는 시설과 시설 사이의 직선거리이며, 주민 거주지에서 수거시설까지의 이동거리를 의미하지 않습니다.

### 4.4 Pearson 상관계수

9개 자치구를 대상으로 두 변수의 선형 관계를 분석했습니다.

- X: 자치구별 65세 이상 주민등록인구 수
- Y: 자치구별 폐의약품 수거시설 기록 수

```text
r = Σ[(x - x평균)(y - y평균)]
    / √(Σ(x - x평균)² × Σ(y - y평균)²)
```

상관계수는 두 변수의 선형 관계를 나타내며 인과관계를 의미하지 않습니다.

### 4.5 월별 수거 처리량 분석

2024년 월별 수거 처리량을 대상으로 다음 지표를 계산했습니다.

- 월별 원자료 수치
- 연간 합계
- 월평균
- 표준편차
- 변동계수
- 최고 및 최저 처리량 월

공식 측정 단위가 검증되지 않은 상태에서는 원자료 수치로 해석합니다.

## 5. 주요 분석 결과

### 5.1 전체 분석 지표

| 지표 | 결과 |
|---|---:|
| 전체 수거시설 기록 | 233건 |
| 전체 인구 1만 명당 시설 기록 수 | 0.654건 |
| 고령인구 1만 명당 시설 기록 수 | 3.239건 |
| 평균 최근접 시설 간 직선거리 | 약 458m |

0.654건과 3.239건은 분석 대상 전체 시설 기록 수를 해당 인구 합계로 나누어 계산한 값입니다.

따라서 자치구별 비율의 단순평균과 구분됩니다.

### 5.2 지역별 시설 분포 격차

전체 인구 1만 명당 시설 기록 비율의 최고·최저 자치구 차이는 약 16.1배로 나타났습니다.

자치구별 인구 규모와 시설 기록 수가 동일한 비율로 분포하지 않는다는 점을 확인했습니다.

### 5.3 시설 간 공간적 분포

| 분석 지표 | 결과 |
|---|---:|
| 전체 평균 최근접 직선거리 | 약 458m |
| 최근접 거리 중앙값 | 약 403m |
| 양천구 평균 최근접 거리 | 약 966m |
| 중구 평균 최근접 거리 | 약 296m |
| 양천구와 중구의 차이 | 약 3.3배 |

시설 간 간격의 차이는 확인되지만, 이 결과만으로 주민의 실제 접근성이 3.3배 차이 난다고 해석할 수는 없습니다.

### 5.4 고령인구와 시설 기록 수의 관계

```text
Pearson r = -0.333
분석 대상 = 9개 자치구
```

고령인구 규모와 시설 기록 수 사이에 약한 음의 선형 관계가 나타났습니다.

분석 대상이 9개 자치구로 제한되어 있고 자료 기준시점도 다르기 때문에, 해당 관계를 서울시 전체의 일반적인 특성으로 해석할 수는 없습니다.

## 6. 웹 대시보드 주요 기능

React 및 Kakao Maps를 이용해 분석 결과를 직접 탐색할 수 있는 웹사이트를 구현했습니다.

### 6.1 수거시설 검색 및 필터

- 시설명 또는 주소 검색
- 자치구별 필터링
- 자료 기준일 필터링
  - 전체 기록
  - 2025년 이후
  - 2025년 이전
- 시설 목록과 지도 연동
- 선택 시설의 주소·기준일·위치정보 확인
- 카카오맵 길찾기 연결

자료 기준일 필터는 시설 목록과 지도에 적용됩니다.

상단 요약 지표와 지역별 분석 차트는 전체 원자료를 기준으로 계산합니다.

### 6.2 Kakao Maps 기반 시설 위치 시각화

- 위도·경도 기반 시설 위치 표시
- 지도 확대·축소 및 전체 보기
- 마커 클러스터링
- 동일 좌표를 사용하는 시설 기록 묶기
- 동일 좌표 마커 클릭 시 시설별 선택 목록 제공
- 선택한 시설 위치 강조

동일 좌표의 시설 기록은 하나의 위치 마커로 묶을 수 있습니다.

따라서 지도 클러스터에 표시되는 숫자는 전체 시설 기록 수와 반드시 일치하지 않습니다.

### 6.3 상단 요약 카드

웹사이트 상단에서 네 가지 주요 지표를 표시합니다.

1. 전체 수거시설 기록
2. 전체 인구 1만 명당 시설 기록 수
3. 고령인구 1만 명당 시설 기록 수
4. 평균 최근접 시설 간 거리

각 카드의 정보 아이콘을 클릭하면 계산 기준, 주요 통계값과 해석상의 주의사항을 확인할 수 있습니다.

### 6.4 지역별 데이터 분석 차트

**가로 막대그래프**

- 전체 인구 1만 명당 시설 기록 수 비교
- 고령인구 1만 명당 시설 기록 수 비교
- 평균 최근접 시설 간 거리 비교
- 자치구별 크기와 순위 비교
- 막대 클릭 시 해당 자치구의 시설 목록·지도 연동

자치구 간 수치 차이를 직관적으로 비교하기 위해 가로 막대그래프를 사용했습니다.

**꺾은선그래프**

- 2024년 월별 수거 처리량 추이
- 자치구 선택에 따른 월별 수치 변경
- 월평균과 월별 변동 분석

시간에 따른 수거 처리량의 변화를 표현하기 위해 꺾은선그래프를 사용했습니다.

**산점도**

- 자치구별 고령인구와 시설 기록 수 비교
- 선택한 자치구 강조
- Pearson 상관계수 표시
- 두 변수의 선형 관계 확인

두 변수 사이의 관계와 분포를 파악하기 위해 산점도를 사용했습니다.

### 6.5 상세 분석 팝업

요약 카드 및 차트의 상세 정보 아이콘을 클릭하면 다음 내용을 확인할 수 있습니다.

- 지표 계산 기준 및 산식
- 자치구별 주요 통계값
- 최고·최저 지역 및 수치 차이
- Pearson 상관계수 해석
- 분석 범위와 데이터 한계
- 기준시점 및 해석 시 유의사항

### 6.6 데이터 출처 및 분석 안내

웹사이트 하단에 데이터 출처 및 분석 유의사항 영역을 구성했습니다.

네 가지 탭으로 정보를 제공합니다.

| 탭 | 제공 정보 |
|---|---|
| 분석 데이터 | 활용 자료, 기준시점, 출처 |
| 분석 방법 | 지표 계산식 및 통계 분석 방법 |
| 데이터 한계 | 분석 범위, 기준시점, 운영 여부 등의 주의사항 |
| CSV 다운로드 | 분석 결과 및 시설 기록 다운로드 |

### 6.7 CSV 다운로드

다음 데이터를 CSV 형식으로 다운로드할 수 있습니다.

- 자치구별 분석 결과
- 전체 수거시설 기록
- 2024년 월별 수거 처리량
- 현재 검색 조건에 해당하는 수거시설 기록

현재 검색 결과 다운로드는 검색어·자치구·자료 기준일 필터를 반영합니다.

한글이 포함된 CSV 파일을 Excel에서 열 수 있도록 UTF-8 BOM을 적용했습니다.

## 9. 실행 방법

Windows 및 PowerShell 환경을 기준으로 설명합니다.

### 9.1 사전 준비

- Git
- Node.js 및 npm
- Python
- Kakao Developers의 지도 JavaScript 키

웹사이트를 실행하기만 하는 경우 Python 데이터 분석 환경은 별도로 준비하지 않아도 됩니다.

### 9.2 GitHub 저장소 다운로드

```powershell
git clone https://github.com/yuna830/medicine-map.git

cd medicine-map
```

### 9.3 프론트엔드 패키지 설치

```powershell
cd frontend

npm install
```

### 9.4 Kakao Maps API 키 설정

`frontend` 폴더에 `.env.local` 파일을 생성합니다.

```dotenv
VITE_KAKAO_MAP_KEY=YOUR_KAKAO_JAVASCRIPT_KEY
```

`YOUR_KAKAO_JAVASCRIPT_KEY` 부분을 본인의 Kakao Maps JavaScript 키로 변경합니다.

Kakao Developers에서 로컬 웹사이트 주소를 허용된 도메인으로 등록해야 합니다.

예시:

```text
http://localhost:5173
```

`.env.local` 파일은 GitHub에 업로드하지 않습니다.

### 9.5 웹사이트 실행

```powershell
npm run dev
```

실행 후 브라우저에서 터미널에 표시된 주소로 접속합니다.

일반적인 기본 주소:

```text
http://localhost:5173
```

### 9.6 프론트엔드 빌드

```powershell
npm run build
```

빌드된 결과물을 확인하려면 다음 명령어를 실행합니다.

```powershell
npm run preview
```

### 9.7 Python 분석 환경 설치

분석 코드를 실행하려면 프로젝트 루트에서 가상환경을 생성합니다.

```powershell
cd C:\github\medicine-map

py -m venv .venv

.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

위 경로는 로컬 프로젝트가 `C:\github\medicine-map`에 있을 때의 예시입니다.

다른 위치에 다운로드했다면 해당 프로젝트 루트에서 실행하면 됩니다.

### 9.8 Python 분석 스크립트

분석 스크립트는 프로젝트 최상위의 `src/` 폴더에 있습니다.

**기본 데이터 처리**

```powershell
.\.venv\Scripts\python.exe src\01_audit.py

.\.venv\Scripts\python.exe src\02_preprocess.py

.\.venv\Scripts\python.exe src\03_validate.py

.\.venv\Scripts\python.exe src\04_analyze.py
```

**보조 데이터 분석**

```powershell
.\.venv\Scripts\python.exe src\07_population_flow.py

.\.venv\Scripts\python.exe src\08_collection_volume.py
```

**양천구 좌표 보완 및 검증**

```powershell
.\.venv\Scripts\python.exe src\10_geocode_yangcheon.py

.\.venv\Scripts\python.exe src\11_verify_yangcheon.py

.\.venv\Scripts\python.exe src\12_merge_yangcheon.py

.\.venv\Scripts\python.exe src\13_validate_geocoded.py
```

양천구 지오코딩을 다시 수행하려면 Kakao REST API 키가 필요합니다.

API 키는 환경변수로 설정하고 GitHub에 업로드하지 않습니다.

기존 결과를 확인하는 목적이라면 지오코딩을 불필요하게 다시 실행할 필요는 없습니다.

**공간 분석 및 웹 데이터 생성**

```powershell
.\.venv\Scripts\python.exe src\14_reanalyze_spatial.py

.\.venv\Scripts\python.exe src\09_prepare_web_data.py
```

각 스크립트는 원본 데이터 또는 이전 단계의 생성 파일을 필요로 할 수 있습니다.

따라서 기존 분석 결과를 재생성할 때는 필요한 입력 파일과 실행 순서를 확인해야 합니다.

### 9.9 웹사이트용 JSON 갱신

프로젝트 루트에서 실행합니다.

```powershell
.\.venv\Scripts\python.exe src\09_prepare_web_data.py
```

필요한 JSON 파일이 생성되었으면 웹사이트의 공개 데이터 폴더로 복사합니다.

```powershell
Copy-Item "data\web\*.json" "frontend\public\data\" -Force
```

데이터를 갱신한 뒤에는 프론트엔드를 다시 실행하거나 브라우저를 새로고침하여 결과를 확인합니다.

## 10. 데이터 해석 시 유의사항

### 10.1 분석 범위 제한

서울시 전체 25개 자치구가 아닌 9개 자치구를 분석했습니다.

따라서 분석 결과를 서울시 전체 수거시설 현황으로 일반화할 수 없습니다.

### 10.2 시설 기록과 운영 시설의 차이

233건은 공개 자료에 수록된 시설 기록입니다.

시설의 현재 운영 여부 또는 수거함 설치 상태까지 확인한 값은 아닙니다.

### 10.3 자료 기준시점 차이

- 시설 위치: 자치구별 자료 기준일 상이
- 인구: 2026년 2분기
- 수거 처리량: 2024년

기준시점이 다른 자료를 직접 비교하여 시설 운영의 효율성을 단정할 수 없습니다.

### 10.4 최근접 직선거리의 한계

시설 간 최근접 거리는 위도와 경도를 바탕으로 계산한 직선거리입니다.

실제 도보·차량 이동거리, 지형, 보행 환경 또는 대중교통 접근성을 반영하지 않습니다.

### 10.5 수거 처리량 측정 단위

2024년 월별 수거 처리량의 공식 측정 단위는 추가 확인이 필요합니다.

단위가 확정되기 전에는 수치를 kg 또는 건수로 임의 해석하지 않습니다.

### 10.6 동일 좌표 기록

서로 다른 시설 기록이 동일 좌표를 가질 수 있습니다.

웹 지도는 동일 좌표의 시설을 하나의 위치 마커로 묶어 표시할 수 있으며, 해당 위치의 개별 기록은 별도의 선택 목록으로 확인할 수 있습니다.

### 10.7 필터 적용 범위

자료 기준일 필터는 시설 목록과 지도에 적용됩니다.

상단 전체 지표 및 통계 차트는 전체 분석 원자료를 기준으로 표시합니다.

- 서울시 전체 25개 자치구로 분석 범위 확대

- 수거 처리량의 공식 측정 단위 및 출처 검증
- 분석 데이터 갱신 과정 자동화

## 12. 프로젝트 의의

본 프로젝트는 공공데이터 수집과 단순 시각화에 그치지 않고, 데이터 정제와 품질 검증, 누락 좌표 보완, 공간 분석 및 웹 대시보드 구현까지 수행한 사례입니다.

서로 다른 출처의 시설 자료를 통합하고, 좌표가 누락된 양천구 기록을 보완하여 총 233건의 시설 기록을 지도에 표현했습니다.

또한 인구 규모를 고려한 시설 기록 비율과 시설 간 공간적 분포 차이를 비교하고, 이를 사용자가 직접 탐색할 수 있도록 구현했습니다.

분석 결과는 지역별 수거 인프라 현황을 비교하고 추가 조사가 필요한 지역을 검토하기 위한 기초 참고자료로 활용할 수 있습니다.
