
# 서울시 폐의약품 수거시설 분포 및 접근성 격차 분석

## 1. 프로젝트 소개

서울시 9개 자치구의 폐의약품 수거시설
공공데이터를 활용하여 시설 분포와
인구 대비 설치 수준을 분석하는 프로젝트입니다.

## 2. 분석 대상

- 마포구
- 양천구
- 구로구
- 관악구
- 중구
- 강동구
- 서초구
- 성북구
- 중랑구

## 3. 활용 데이터

- 자치구별 폐의약품 수거시설 위치 데이터
- 서울시 등록인구 데이터
- 서울시 폐의약품 수거 처리량
- 서울시 길단위 유동인구

## 4. 사용 기술

- Python
- pandas
- Jupyter Notebook
- Matplotlib

## 5. 실행 방법

### 라이브러리 설치

pip install -r requirements.txt

### 데이터 품질 검사

python src/01_audit.py

### 전처리 및 인구 데이터 결합

python src/02_preprocess.py

## 6. 분석 시 유의사항

수거시설 원본 자료의 기준일이 자치구별로
다르므로 시설 기록 수를 현재 운영시설 수로
해석하지 않습니다.

공간 접근성 분석은 좌표 품질과
추가 공간 데이터 확보 여부를 확인한 후 진행합니다.
